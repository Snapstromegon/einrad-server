# German national Artistic Freestyle supplements

This folder contains only German-specific additions and procedures. For the
base Artistic Freestyle rules, start with the applicable IUF edition:
[individual](../../iuf/artistic-freestyle/individual.md),
[pairs](../../iuf/artistic-freestyle/pairs.md), and
[groups](../../iuf/artistic-freestyle/groups.md). Then apply the relevant
national supplement below.

- [Video qualification](video-qualification.md)
- [Judging and jury operations](judging.md)
- [Event hosting](event-hosting.md)

## Version and scope

The supplied concept marks specific provisions for the 2027 season. Its note
that the 2026 season used IUF 2019 is historical and does not determine the
base edition for 2027 or later. Use the IUF edition specified by the current
event/federation, then apply relevant German-only provisions. See the
[specificity chain and source list](../../README.md).
