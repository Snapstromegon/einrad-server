# Unicycle competition references

These notes summarize the supplied official rule documents for future agents. They
are quick references, not substitutes for the rule text or event-specific
announcements. Use the note matching the discipline and competition level, then
check the cited source section before making a consequential decision.

## Specificity chain for 2027 and later

1. Match the event's governing body, discipline, and season.
2. Start with the rulebook edition specified by the event. The supplied final
   **IUF 2026 Competition Rulebook** is the reference edition for these notes;
   check for any later IUF edition or event-specific amendments.
3. For German national Artistic Freestyle, apply the relevant
   [German-specific supplements](german/freestyle/README.md) only to the
   German rules they address. They do not replace the IUF discipline rules.
4. The supplied German concept marks provisions for 2027. Its statement that
   the 2026 season used IUF 2019 is historical and does not set the base
   edition for 2027 or later. Confirm the applicable base edition with the
   current federation or event instructions rather than assuming.

The hosting-guidelines PDF includes an application deadline for the 2026
selection cycle. That deadline has passed; use the current call for future
applications.
