# IUF rule references

These summaries use the final **2026 IUF Competition Rulebook**, dated
September 2026, as the supplied reference edition for 2027 and later. Use the
edition specified by the event and check for later amendments.

## Summarized disciplines

- [Artistic Freestyle](artistic-freestyle/README.md):
  [Individual](artistic-freestyle/individual.md),
  [Pairs](artistic-freestyle/pairs.md), and
  [Groups](artistic-freestyle/groups.md)
- [Track racing](track-racing.md)
- [X-Style](x-style.md)
- [Jumps](jumps.md)
- [IUF Competition Rulebook 2026 PDF](../../sources/iuf-rulebook-2026.pdf)

The rulebook also includes Road Racing, Mountain Unicycling, Cyclocross,
Standard Skill, Flatland, Street, Trials, Speed Trials, Hockey, and Basketball.
Those disciplines are not separately summarized in this folder; consult their
chapters in the source PDF rather than inferring their rules from these notes.
