# Artistic freestyle: pairs

## Scope

This page summarizes the IUF base rules. Use the IUF edition specified for the
competition. German national supplements are kept separately in
[German freestyle references](../../german/freestyle/README.md).

## Competition shape

- A pair routine has two riders and follows the same core judging components
  and **3-minute maximum** as individual freestyle. The IUF age group for a
  pair is determined by the older rider; an Expert / Junior Expert category
  choice, where offered, must be stated in advance. (IUF 2026, §§6B.8.1,
  6E.5.2, pp.111, 130.)
- In skill-level categories, the IUF guidance is to average the pair's skill
  levels when determining category. Those categories are an alternative used
  by organizers of smaller competitions, not a universal requirement.
  (IUF 2026, §§6B.7-6B.7.1, p.110; §6E.6, p.130.)
## Pair-specific judging

IUF scoring uses Technical (45%), Performance (45%), and Dismounts (10%).
Judges assess the pair's overall difficulty rather than simply rewarding the
stronger rider's best solo skills. Pair-specific performance criteria include
unison, balance between partners, spatial awareness, shared responsibility,
and how the partners' relationship reflects the music. (IUF 2026,
§§6D.1-6D.3.3.1, pp.120-126.)
