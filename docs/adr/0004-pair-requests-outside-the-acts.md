# Pair requests live outside the acts

A rider's starts are read from acts and act participants only; the only thing kept outside them is a pair request (Paaranfrage), a rider waiting for a partner who isn't linked yet, which gets its own table instead of being a pair act with one rider. Incomplete groups are acts with too few riders, so a one-rider pair act would look like the consistent choice, but every reader of acts (timeplan, startlist, categories, music, check-in, finals, metrics) would then have to filter out pairs that aren't pairs yet, and confirming a cross-club pair where both clubs filed a request would mean merging two acts into one; with a separate table, confirming is one new act and deleting the requests.

The cost is that start fees count pair requests separately from act participants, and an act fee waiver can't apply to a pair request (a rider fee waiver can).
